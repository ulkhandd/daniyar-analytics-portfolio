# Data Notes

The raw `loan_data_2007_2014.csv` file is not tracked in this repository.

Reasons:

- The extracted CSV is large.
- Public repositories should avoid committing bulky raw datasets when the project can be reviewed through reports, methodology, and generated results.
- Reproduction should use a local copy of the original dataset.

Expected local filename:

```text
loan_data_2007_2014.csv
```
