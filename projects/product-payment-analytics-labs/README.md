# Payment & Product Analytics Labs

## Purpose

This folder collects additional GitHub-viewable notebooks from product analytics and payment analytics lab work. These are supporting artifacts that show hands-on notebook analysis beyond the main resume projects.

## Notebooks

- `notebooks/checkout-methods-analysis.ipynb` - conversion rate and cost analysis by checkout payment method
- `notebooks/user-classification-analytics.ipynb` - user identity-signal cleaning and classification analysis
- `notebooks/payment-auth-clearing-settlement-lab.ipynb` - authorization, clearing, settlement, decline, and recovery analysis

## Review Notes

The notebooks are public portfolio copies. Execution outputs and notebook metadata were removed so the full source is easy to inspect in GitHub without exposing local environment details.
